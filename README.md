# Aliza Ghaffar - Certified Agentic AI Engineer & Full-Stack Developer Portfolio

This is a modern, responsive, and animated personal portfolio website for Aliza Ghaffar, built with Next.js, TypeScript, and Tailwind CSS. It showcases her professional summary, education, technical skills, projects, development approach, and career interests with a focus on Agentic AI and Full-Stack Development.

## ✨ Features

*   **Modern UI/UX**: Clean, professional design with a dark theme.
*   **Responsive Layout**: Optimized for desktop, tablet, and mobile devices.
*   **Animations**: Subtle scroll-based and entry animations using lightweight CSS transitions for an engaging user experience.
*   **Semantic HTML & Accessibility**: Built with best practices for accessibility and SEO.
*   **Next.js App Router**: Utilizes the latest Next.js features for efficient development.
*   **Tailwind CSS**: Utility-first CSS for rapid and consistent styling.
*   **TypeScript**: Ensures type safety and improves code quality.

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Make sure you have Node.js (v18 or higher) and npm (or yarn/pnpm) installed on your system.

*   [Node.js](https://nodejs.org/)
*   [npm](https://www.npmjs.com/) (usually comes with Node.js)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/aliza-ghaffar-portfolio.git
    cd aliza-ghaffar-portfolio
    ```
    *(Note: Replace `your-username/aliza-ghaffar-portfolio` with the actual repository URL if you fork it.)*

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```
